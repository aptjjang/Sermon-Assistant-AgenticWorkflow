# 현장 기록

수노에서 실제로 해 보고 확인한 것을 여기에 쌓는다. **이 파일의 '확인된 결과'는 다른 참고 파일의 추정치보다 우선한다.**
스타일을 정하거나 수정안을 내기 전에 이 파일을 먼저 읽는다.

## 확인된 결과

| 날짜 | 모델 | 조건 (BPM · Style · 가사 줄) | 들린 문제 / 결과 | 정리된 규칙 |
|---|---|---|---|---|
| (아직 없음) | | | | |

기록이 쌓여 같은 결론이 두 번 이상 나오면, 해당 참고 파일(`lyric-rules.md`, `suno-style.md`)과 `scripts/lyric_check.py`의 기준값을 고친다.

## 사용자가 정한 것

| 항목 | 값 |
|---|---|
| 기본 보컬 | (정해지면 적는다) |
| 고정 목소리(Voices) | (정해지면 적는다) |
| 구글 드라이브 저장 폴더 | (처음 저장할 때 물어 적는다) |

## 조사 자료와 다르게 정한 것

| 항목 | 조사 자료 | 이 스킬 | 이유 |
|---|---|---|---|
| 곡 전체 분량 | 한글 600~900자 내외 | 부르는 글자 약 200~300자, 350자를 넘으면 주의 | 자료가 제시한 뼈대(절 4줄 7~12자, 후렴 4줄 5~9자)대로 쓰면 200~300자가 된다. 70 BPM에서 4분은 약 70마디이고 한 줄이 두 마디쯤 차지하므로, 600자를 넣으면 자료가 경고한 '몰림'이 생긴다. 실험으로 확인할 것 |
| 줄 끝 받침 | 받침 없는 열린 모음 | 열린 모음이 기본. ㄴ·ㄹ·ㅁ·ㅇ 받침은 허용, ㄱ·ㄷ·ㅂ 소리 받침만 '주의' | 울림소리 받침은 소리를 끌 수 있다. 실험 2번으로 확인할 것 |
| 업템포 찬양 Style | 없음 | 제안 문구 1개 추가 | 기쁨·축제 성격의 글에 쓸 출발점이 필요하다. 검증되지 않았다 |

## 실험 대기 목록

아직 추정인 것들이다. 사용자가 해 보겠다고 할 때 안내하고, 결과를 위 표에 적는다.

| 순서 | 실험 | 방법 | 판단 기준 |
|---|---|---|---|
| 1 | 글자 수 한계 | 같은 후렴을 한 줄 6·9·12자 판으로 각각 3번 생성 (70 BPM) | 몰림·늘어짐이 사라지는 최대 글자 수 |
| 2 | 받침 | 글자 수는 같고 줄 끝만 다른 두 판(열린 모음 / 받침) | 긴 음의 발음이 또렷한가 |
| 3 | 시점 구조 | 같은 글로 A형(1인칭만)과 B형(3인칭 장면 → 1인칭 고백)을 만들어 몇 분께 들려 드린다 | "내 이야기 같다"는 반응 |
| 4 | 모델 버전 | 같은 가사·Style로 v6와 v5.5 각 3번 | 한국어 발음과 감정 표현 |
| 5 | 반음 올리기 | `[Key Change]` 태그 / Style에 `half-step key change on final chorus` | 실제로 올라가는 비율 |
| 6 | 장르 말 | `Korean CCM ballad` / `Korean worship ballad` / `K-ballad, Christian lyrics` | 원하는 질감에 가까운 쪽 |
| 7 | 발음 문구 | `Clear Korean pronunciation`을 넣은 판과 뺀 판 각 3번 | 발음 차이가 들리는가 |
| 8 | 분량 | 부르는 글자 200자·300자·400자 판 | 곡 길이와 몰림 |
